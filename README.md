# Simple Webscraper 

Author: Rylee Hilde

Semester: Spring 2026

## Note:
- This only parses the website [Books To Scrape](https://books.toscrape.com/catalogue/category/books_1/index.html)

## Compiling and Using

First, install Ruby from the Ruby website, and after installing, run:
```bash
bundle install
```

in the command line to install additional dependencies.

To run the webscraper, make sure you're in the project directory, and run:

```bash
ruby webscraper.rb
```

in the command line.
